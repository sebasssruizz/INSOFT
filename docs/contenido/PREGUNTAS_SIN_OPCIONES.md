# PREGUNTAS SIN OPCIONES — banco de pterigión (para la docente)

respuestas esperadas) es de **respuesta abierta**: solo enunciado y respuesta
esperada, SIN opciones A-D. Por decisión del equipo NO se inventan
distractores. Este listado es la lista para la docente: si decide cuáles van
como opción múltiple, hay que definir por pregunta tres distractores creíbles
y marcar la correcta; el equipo las carga entonces por "Agregar preguntas"
(source=teacher, approved tras revisión). Mientras tanto NADA se importa.
