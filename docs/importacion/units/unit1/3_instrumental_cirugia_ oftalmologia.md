## Instrumental para cirugía Oftalmológica

El instrumental cirúrgico oftalmológico se clasifica en básico y especializado, requiriendo reconocimiento, montaje, manipulación y cuidado adecuado en cada fase:

**Instrumental básico**:
- **Pinzas**: Adson (tissue), Bishop-Harmon (fenestrated), Russian (for dressing). Se usan para manipulación de tejidos y hemostasia.
- **Tijeras**: Iris (corte fino), Westcott (curved, safe for ocular tissue), surgical microscissors. Para corte de tejidos y suturas.
- **Separadores**: Barra de Barraquer, Van Herick, para mantener la apertura del campo quirúrgico.
- **Blefaróstatos**: Para mantener los párpados abiertos durante el procedimiento, previniendo el cierre reflejo y el daño corneal.
- **Portaagujas**: Holders con diferentes puntas (Castroviejo, Cilia) para manipulación de suturas.

**Instrumental especializado para microcirugía**:
- **Micropinzas de microdisección**: Para trabajo en planos planos y delicados tejidos oculares.
- **Microsujecionadores**: Para aspiración de fluidos y desechos del campo quirúrgico.
- **Electrobisturí**: Para corte y coagulación controlada de tejidos oculares.
- **Porta lentes y lentes de visaje**: Para visualización del segmento anterior y posterior.

**Cuidado y mantenimiento**: Todos los instrumentos deben ser limpiados inmediatamente después del uso, pasar por proceso de desinfección o esterilización (autoclave para instrumentos reutilizables), y almacenados en condiciones secas y organizadas. Se deben realizar conteos quirúrgicos antes y después del procedimiento para evitar dejar instrumentos en el paciente. El instrumental debe inspeccionarse regularmente para detectar corrosión, deformación o desgaste que pudiera comprometer la seguridad del paciente.

Una instrumentación adecuada, organizada y en condiciones óptimas es esencial para la eficiencia quirúrgica y la prevención de complicaciones durante la cirugía oftalmológica.
