## Origen de las preguntas de relleno (análisis)

- Ningún seed, migración ni proceso automático del código en `main` crea preguntas de relleno:
  `app/seed/seed_questions.py` contiene solo preguntas reales del temario.
- Las filas sospechosas fueron creadas **vía la API del banco docente**
  (`POST /api/content/subtopics/{id}/questions/bank`) el 2026-09-30 por 5 cuentas de
  prueba (created_by 42, 45, 47, 47, 49, 51), en ráfaga (< 1 s entre filas): típico de un
  script ad-hoc de carga/prueba del desarrollador (estilo `backend/app/scripts/run_qa_batch.py`,
  que existe sin trackear en local para pruebas de /api/ai/ask pero NO crea preguntas).
- Consecuencia: NO corre automáticamente; no hay nada que desactivar en el repo.
  Recomendación: correr este tipo de scripts solo contra la base local de desarrollo y
  borrar/limpiar sus datos una vez hecho el experimento.
